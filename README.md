# 모던 단일 HTML 계산기 웹앱 (Modern Single-File Web Calculator)

단일 HTML 파일(`index.html`)로 구현된 모던하고 세련된 디자인의 웹 계산기입니다. 별도의 의존성이나 빌드 과정 없이 웹 브라우저에서 바로 열어 사용할 수 있습니다.

## 주요 기능

1. **기본 및 확장 연산**
   - 사칙연산 (`+`, `−`, `×`, `÷`)
   - 퍼센트 연산 (`%`) 및 부호 반전 (`±`)
   - 소수점 부동소수점 오차 보정 (최대 12자리 정밀도)
   - 0으로 나누기 예외 처리 (`Error` 표기)

2. **사용자 경험 (UX & Design)**
   - 글래스모피즘(Glassmorphism) 기반 세련된 다크/라이트 테마
   - 입력 자릿수에 따른 디스플레이 폰트 크기 자동 조절
   - 천 단위 콤마(`,`) 실시간 포맷팅
   - 터치 및 클릭 반응 애니메이션

3. **키보드 단축키 지원**
   - 숫자: `0` ~ `9`, `.`
   - 연산자: `+`, `-`, `*`, `/`
   - 결과 계산: `Enter` 또는 `=`
   - 삭제/지우기: `Backspace` (1글자 지우기), `Esc` (전체 초기화 AC)

4. **계산 내역 (History)**
   - 이전 계산 기록을 슬라이드 드로어로 확인 가능
   - 기록된 결과를 클릭 시 현재 입력값으로 재사용

## 실행 방법

- `index.html` 파일을 크롬, 엣지, 사파리 등 모던 브라우저로 더블 클릭하여 실행합니다.
- 또는 로컬 정적 웹 서버를 통해 실행할 수 있습니다.
